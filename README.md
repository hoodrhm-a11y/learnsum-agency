# LearnSum Agency 🌱

An automated content team for the **LearnSum** Facebook page (and Instagram, optional): short, warm, useful posts for
parents of kids in Kindergarten to grade 8, with gentle showcases of the LearnSum app (learnsum.ca).
It runs on GitHub Actions in this public repository, so the Actions minutes are free.

## The team

| Agent | When | What it does |
|---|---|---|
| **Writer / planner** | Sundays ~8:30 am Toronto | Plans next week: 7 posts (4 short videos + 3 carousels), one a day. Checks the last 28 days of results first |
| **Designer** | Sundays | Renders every post in the LearnSum look (navy, Pip green, sunshine gold, real app screens) and puts previews in a pull request |
| **Checker** | Sundays | Automatic safety checks (below), then the weekly reviewer looks at every preview before approving |
| **Publisher** | Daily, 7:30 pm Toronto | Posts the approved post that is due |
| **Comment helper** | Every 3 hours, daytime | Hides spam, answers simple questions (price, ages, devices, safety), flags anything personal to you |
| **Connection check** | Mondays | Makes sure the Facebook connection still works and opens an issue if it doesn't |

**Your job:** nothing day to day. You get a short weekly message. If a comment needs you, an issue called
"💬 Comments that need you" appears here (it never quotes the comment, because this repository is public).

## Safety rails
- **No made-up numbers.** Every number in a post must exist in [`agent/facts.yaml`](agent/facts.yaml), a list of checked facts
  with sources (LearnSum product facts, Canadian 24-Hour Movement Guidelines, school calendar). Anything else is rejected
  automatically. Example fields must start with "Example".
- **Kind and careful.** Words like "genius", "top of the class", "falling behind", "lazy" and any mention of diagnoses
  (ADHD, autism, dyslexia) are blocked. No promises of results. No real children's photos.
- **Nothing posts without approval.** Only posts merged into `queue/approved/` on `main` are published.
- **Original work only.** Every visual, layout and music track is generated by this code. No reposting.
- **Privacy.** Comment ids are stored, never comment text or names.

## One-time setup (do this when you're ready to go live)

### 1. Page token (same Meta developer app as Loonie Lens)
1. Open **developers.facebook.com → Tools → Graph API Explorer**, choose your existing app.
2. **Get User Access Token** with: `pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_engagement,
   pages_read_user_content, read_insights, business_management` (add the `instagram_*` ones only if you link Instagram).
3. Extend it (Access Token Debugger → *Extend Access Token*), then call `GET /me/accounts`.
   The `access_token` next to **LearnSum** is the Page token; note the Page `id`.

### 2. Add GitHub secrets
This repository → **Settings → Secrets and variables → Actions → New repository secret**:

| Secret | Value |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API key (the same one as Loonie Lens is fine) |
| `META_PAGE_ID` | LearnSum Facebook Page id |
| `META_PAGE_TOKEN` | LearnSum Page token |
| `META_IG_USER_ID` | Instagram user id (optional) |

Secrets stay private even though the repository is public. Until they are added, every job skips quietly.

### 3. Let Actions open pull requests
**Settings → Actions → General → Workflow permissions** → *Read and write permissions* and tick
*Allow GitHub Actions to create and approve pull requests*.

### 4. First run
Actions → **Weekly content** → *Run workflow*. Review the pull request, then merge.
To test without posting: Actions → **Publish due posts** → *Run workflow* with `dry_run = 1`.

## Folder map
```
agent/      facts.yaml (checked facts), calendar.yaml (school-year moments), plan_week.py (writer), validate.py (checker), report.py
engine/     render_reel.py, render_carousel.py, music.py, brand.py (the LearnSum look, Pip, phone frames)
assets/app/ real LearnSum app screens used in "app" scenes (today, numline, rocket, balance, maker, arcade)
publish/    meta.py (Facebook/Instagram API), publish_due.py, storage.py
comments/   assistant.py (comment helper)
queue/      pending → approved → posted   (one JSON file per post)
samples/    the first sample week, with previews in previews/
examples/   one reel and one carousel that teach the writer the format
```

## Post format (short version)
A **reel** is a list of scenes: `hook`, `stat`, `bars`, `tips`, `statement`, `app`, `cta` (hook first, cta last).
A **carousel** is a list of slides: `cover`, `points`, `compare`, `app`, `cta`.
Render one locally:
```
python -m engine.render_reel examples/reel_counting_dinner.json
python -m engine.render_carousel examples/carousel_progress_report.json
```
